# 릴리스 노트

새 릴리스가 위에 옵니다. 릴리스 본문에 그대로 붙여 쓰는 글입니다.

## 0.1.17

0.1.16 위에 그대로 덮어 설치됩니다. 게임과 세이브는 그대로 남습니다.

### 최신 스냅드래곤에서 프레임이 떨어지고 터치가 씹히던 문제를 고쳤습니다 (#5)

**갤럭시 S26 Ultra(Adreno 840)에서 세이브 목록, 영지, 전투가 20 FPS 안팎으로 떨어지고
터치가 몇 번씩 씹히던 문제를 고쳤습니다.** 실제 S26 Ultra를 빌려 확인했습니다. 이제
세이브 목록, 영지, 전투 모두 60 FPS를 유지하고 터치도 바로 먹습니다. 1280x720과
1920x1080 모두 같습니다. 갤럭시 S22에서도 같은 전투가 약 22 FPS에서 60 FPS가 됐습니다.

원인은 그래픽 드라이버가 아니라 게임과 화면 사이의 대화 방식이었습니다. 게임은 한
프레임에도 수백 번 화면 쪽에 묻고 답을 기다리는데, 최신 안드로이드(리눅스 6.6 이후)의
작업 순서 방식에서는 이 기다림이 크게 늘어졌습니다. 그래서 게임이 쓰는 그래픽
라이브러리(Gladio)를 다키스트 던전에 맞게 고쳐서 런처에 넣었습니다. 같은 질문은 한 번만
묻고, 답이 필요 없는 일은 기다리지 않으며, 기다릴 때는 코어를 붙잡지 않고 잠듭니다.

- **설정 → 화면에 "프레임 제한"이 생겼습니다.** 30 / 60 / 제한 없음 중에서 고를 수 있고,
  기본값은 60입니다. 전에는 제한이 없어서 메뉴와 로딩 화면에서도 1초에 수백 장을 그리며
  배터리와 발열만 늘었습니다. 턴제 게임이라 30으로 두면 발열이 더 줄어듭니다
- 0.1.16에서 시험용으로 넣었던 "스냅드래곤 기기 · 기기 드라이버 (Vortek + Zink)"는 이제
  필요 없습니다. 끊김 때문에 바꾸셨다면 자동으로 되돌려 주세요
- **설정 → 그래픽에 "FPS 표시"가 생겼습니다.** 게임 화면 위에 초당 프레임, 메모리, CPU
  클럭을 띄웁니다. 끊김을 제보할 때 이 숫자가 있으면 원인을 찾기 쉽습니다

### 설정

- **그래픽 드라이버를 드롭다운으로 고릅니다.** 펼치면 항목마다 누구를 위한 것인지 설명이
  나옵니다
- **"고급 설정"을 펼치면 Vulkan 드라이버(Turnip / Vortek)와 OpenGL 방식(Gladio / Zink /
  VirGL)을 따로 고를 수 있습니다.** Winlator처럼 직접 조합하고 싶은 분을 위한 것입니다.
  직접 받은 Vulkan 드라이버 파일(AdrenoTools zip)도 여기서 넣습니다
- **설정에 들어갔다 나오면 Steam 로그인이 풀리던 문제를 고쳤습니다.** 화면을 옮길 때마다
  Steam에 다시 로그인하고 있었고, 네트워크가 느리면 로그인 정보를 지워 버렸습니다

### DLL 모드

**모드 관리자에 "DLL 모드" 탭이 생겼습니다.** `winmm.dll` 같은 DLL 모드를 쓰고 싶다는
요청에 따른 기능입니다.

- **`DD1/dll`에 DLL을 넣고 플레이를 누르면, 게임이 실행하는 `Darkest.exe` 옆에 들어갑니다.**
  PC 안내처럼 `_windows/win64` 폴더째 넣어도 같은 곳으로 갑니다. 폴더 구조를 맞춰 넣은
  다른 파일은 게임 폴더의 같은 위치로 덮어써집니다
- 넣은 DLL은 Wine에 들어 있는 같은 이름의 DLL보다 먼저 쓰입니다. 전에는 파일을 넣어도
  Wine이 자기 것을 써서 DLL 모드가 동작하지 않았습니다
- 파일을 빼면 다음 플레이 때 게임의 원래 파일로 돌아갑니다
- DLL 모드 탭에서 파일마다 "사용 중 / 다음 플레이 때 적용 / 빠짐"을 확인할 수 있습니다
- **이전의 `DD1/overrides` 폴더는 `DD1/dll`로 자동으로 옮겨집니다**

### DD1 폴더

- **모드 관리자의 폴더 변경은 이제 "DD1 폴더"를 고릅니다.** 고른 폴더 안에 `mods`와 `dll`
  폴더를 만들어 씁니다. 전에 모드 폴더를 직접 지정하셨다면 다시 고르기 전까지 그대로
  씁니다

### 세이브

**세이브 화면을 새로 만들었습니다.**

- 오른쪽 목록에 세이브가 영지 이름과 저장 시각으로 나옵니다. 이름 앞의 불 색으로 상태를
  보여 줍니다: 초록 같음, 주황 다름, 노랑 클라우드에만, 빨강 이 기기에만
- 왼쪽에는 고른 세이브의 이 기기와 클라우드 정보가 나란히 나옵니다. 양쪽이 같으면 초록
  테두리가 들어오고, 다르면 어느 쪽이 더 최근인지 알려 줍니다
- "이 기기에서 지우기"가 생겼습니다. 지우기 전에 스냅샷을 남기고, 클라우드 사본은
  그대로 둡니다
- 스냅샷은 별도 탭으로 옮겼습니다. 전송 기록은 결과만 보여 주고, "자세히"를 누르면
  파일별 기록이 나옵니다
- 올리기나 받기가 진행 중이면 다른 작업을 막습니다
- **클라우드로 올린 세이브를 PC에서 받을 때 꼬이던 문제를 고쳤습니다.** 원정 중에만 생기는
  파일(`persist.raid.json` 등)이 클라우드에 남아 있어서, 마을 세이브를 올려도 PC가 옛 원정
  파일까지 함께 받았습니다. 이제 올릴 때 폰에 없는 파일은 클라우드에서도 지웁니다
- 올리기에 실패하면 Steam이 알려 준 이유를 함께 보여 줍니다
- 앱을 켤 때 클라우드 세이브 목록을 미리 읽어 두어서, 세이브 화면이 바로 열립니다

### 모드 관리자

- **앱을 켜고 로그인이 끝나면 창작마당 모드를 바로 동기화합니다.** 모드 관리자를 열지
  않아도 됩니다. 새로 구독한 모드를 받는 동안에는 상단 알림에 진행 상황이 나오고, Steam에서
  구독을 취소한 모드는 폰에서 지웁니다
- 목록의 카드 높이를 맞췄습니다

### 화면

- 카드, 버튼, 확인 창을 둥글게 다듬고, 홈과 메뉴에 앱 아이콘을 넣었습니다
- 알림이 화면 오른쪽 아래의 카드로 나옵니다. 예를 들어 "창작마당 모드 2개를
  동기화합니다", "구독 취소한 모드 1개를 지웠습니다"처럼 나옵니다
- 진단 로그를 켜면 `DD1/logs/logcat.txt`에 안드로이드 쪽 기록도 함께 남습니다

## 0.1.16

0.1.15 위에 그대로 덮어 설치됩니다. 게임과 세이브는 그대로 남습니다.

### 최신 스냅드래곤에서 새 장면마다 심하게 끊기는 문제 (#5)

**갤럭시 S26 Ultra(Adreno 840)에서 영지 진입, 대사, 메뉴처럼 처음 나오는 장면마다 1~2분씩
프레임 단위로 끊기고 터치가 씹힌다는 제보가 있었습니다.** 아직 원인을 찾지 못했습니다.
개발자에게 이 기기가 없어서, 이번 버전은 시험해 볼 방법과 원인을 찾을 기록을 넣는 데
초점을 뒀습니다.

- **그래픽 드라이버에 "스냅드래곤 기기 · 기기 드라이버 (Vortek + Zink)"가 생겼습니다.**
  Turnip 대신 기기에 들어 있는 Qualcomm 드라이버로 그립니다. 제보해 주신 분이 시험한
  조합 중 가장 나았습니다. 자동 선택은 그대로 Turnip이니, 끊김이 심한 기기에서만
  설정 → 그래픽에서 골라 주세요
- **그래픽 드라이버 이름에 두 드라이버를 모두 적었습니다.** 예를 들어 "엑시노스·그 외
  기기 (Vortek + VirGL)"처럼 나옵니다. 전에는 뒤쪽 이름만 나와서 Turnip이 고정인 것처럼
  보였습니다

### 진단 로그 저장

**설정 → 일반의 "진단 로그 저장"을 켜면 게임을 실행하는 동안의 기록이 파일로 남습니다.**
문제가 있는데 원인을 모를 때 이 파일을 이슈에 함께 올려 주시면 큰 도움이 됩니다.

- `DD1/logs/wine-log.txt`: Wine과 box64가 남기는 기록입니다. 줄마다 시각이 붙어 있어서
  게임이 멈춘 때를 찾을 수 있습니다
- `DD1/logs/device.txt`: 기기, GPU, 그래픽 드라이버, 해상도 같은 설정 정보입니다
- 직전 실행의 기록은 `wine-log-previous.txt`로 남습니다. 게임을 다시 켜도 문제가 있던
  실행의 기록이 지워지지 않습니다
- 켜는 동안 게임이 조금 느려질 수 있습니다. 필요할 때만 켜 주세요

### 그 밖에

- 다운로드나 검사가 진행 중일 때 게임을 앱 안으로 옮기는 작업이 건너뛰어지면, 앱을 끄기
  전까지 다시 시도하지 않던 문제를 고쳤습니다

## 0.1.15

0.1.14 위에 그대로 덮어 설치됩니다. 게임과 세이브는 그대로 남습니다.

### 던전·영지 로딩이 몇 분씩 걸리던 문제 (#4)

**게임이 내부 저장공간(`DD1/game`)에 있으면 장면이 바뀔 때마다 로딩이 수 분, 길게는
20분 가까이 걸렸습니다.** 안드로이드에서 내부 저장공간의 파일은 하나를 열 때마다
저장소 계층을 거치는데, 던전에 들어가거나 영지로 돌아올 때 게임은 파일을 수천 개
엽니다. 0.1.13에서 새로 설치하면 게임이 이곳에 들어가도록 바꾼 것이 원인입니다.
0.1.13 노트에는 타이틀 화면까지의 시간(27초 대 40초)만 적었는데, 실제 플레이 중
로딩은 그보다 훨씬 크게 차이가 났습니다. 갤럭시 S22와 S25+에서 확인했습니다.

- **새로 설치하면 게임은 다시 앱 안에 들어갑니다**
- **게임이 `DD1/game`에 있으면 업데이트 후 처음 켤 때 자동으로 앱 안으로 옮깁니다.**
  설치만 하면 됩니다. 약 4 GB를 복사하므로 그만큼 여유 공간이 잠시 필요하고, 세이브는
  영향받지 않습니다. 공간이 모자라 옮기지 못하면 홈 화면에 안내가 남고, 공간을 비운 뒤
  누르면 다시 옮깁니다
- 설정의 "내부 저장공간으로 옮기기"는 없앴습니다. 모드와 DLL은 아래처럼 밖에서 넣습니다
- 옮긴 뒤에는 이전 위치의 파일을 지우는 동안 지운 파일 수가 나옵니다. 전에는 100%에서
  멈춘 것처럼 보였습니다. 끝날 때까지 앱을 끄지 말아 주세요

### 모드와 DLL은 밖에서 넣습니다

게임이 앱 안에 있어도 파일 관리자로 모드와 게임 파일을 다룰 수 있습니다.

- **모드는 `DD1/mods`에 넣습니다.** 플레이를 누르면 새로 넣은 모드가 들어가고, 폴더에서
  뺀 모드는 빠집니다. 폴더 안의 모드를 고치면 다음 플레이 때 고친 내용으로 다시 들어갑니다
- **게임 파일을 바꾸거나 DLL을 넣을 때는 `DD1/overrides`에 넣습니다.** 게임 폴더와 같은
  구조로 넣으면 플레이를 누를 때 그 자리에 덮어씌웁니다. 예를 들어
  `DD1/overrides/_windows/win64/example.dll`은 `Darkest.exe` 옆에 들어갑니다
- overrides에서 파일을 빼면 다음에 플레이를 누를 때 게임의 원래 파일로 돌아갑니다
- 홈 화면의 게임 파일 열기를 누르면 `DD1/overrides`를 열 수 있습니다

0.1.13 위에 그대로 덮어 설치됩니다. 게임과 세이브는 그대로 남습니다.

### 돋보기

**왼쪽 여백의 돋보기 버튼을 누르면 게임 화면이 1.5배 커집니다.** 스킬 설명이나 아이템
글씨처럼 휴대폰에서 작게 보이는 것을 크게 볼 때 씁니다. 다시 누르면 원래대로 돌아옵니다.

- 마지막으로 터치한 곳을 중심으로 커집니다
- 커져 있는 동안 오른쪽 여백 위에 작은 지도가 나옵니다. 게임 전체 화면이 작게 보이고,
  지금 보이는 부분이 빨간 테두리로 표시됩니다
- 지도를 누르거나 끌면 보는 위치가 옮겨집니다
- 커진 상태에서도 화면에 보이는 그대로 누르면 됩니다
- 여백이 좁은 태블릿에서는 지도가 게임 화면 오른쪽 위 구석에 작게 나옵니다
- 키보드(ABC)를 켜면 확대는 꺼집니다

## 0.1.13

게임 파일을 휴대폰에서 직접 다룰 수 있게 하는 데 초점을 둔 버전입니다. 커뮤니티와
이슈(#2, #3)로 알려 주신 내용을 반영했습니다. 감사합니다.

> **이번 버전은 기존 앱 위에 덮어 설치되지 않습니다.** 새 앱으로 따로 설치되니, 아래
> "이번 버전은 새 앱으로 설치됩니다"의 옮기는 순서를 먼저 봐 주세요.

### 한눈에 보기

- **새 앱으로 설치됩니다.** 윈레이터(또는 그 포크)가 깔려 있어도 함께 설치됩니다
- **게임이 `내장 저장공간/DD1/game`에 설치됩니다.** 파일 관리자로 열어서 모드나 DLL을
  넣을 수 있고, 앱을 지워도 게임이 남습니다
- **모드는 `DD1/game/mods`에 넣으면 바로 적용됩니다**
- **홈 화면에 게임 파일 열기, 게임 파일 검사 및 복구가 생겼습니다.** 넣은 파일 때문에
  게임이 켜지지 않아도 고칠 수 있습니다
- **다운로드가 끊겨도 처음부터 다시 받지 않고 이어서 받습니다**
- **던전에서 ◀ ▶ 버튼을 누르고 있으면 걷습니다**
- **게임을 켤 때 검은 화면 대신 로딩 화면이 나옵니다**
- **APK가 168 MB에서 113 MB로 작아졌습니다**
- 모드 크기 제한(512 MB)을 없앴고, 게임을 다시 받아도 모드가 남습니다
- 모드 관리자와 설정 화면을 가로 휴대폰에 맞게 다시 정리했습니다

### 이번 버전은 새 앱으로 설치됩니다

**0.1.13은 기존 앱 위에 덮어 설치되지 않고, 옆에 새 앱으로 따로 설치됩니다.** 앱을
서명하던 키를 잃어버려서, Android가 같은 앱의 업데이트로 받아 주지 않기 때문입니다.
죄송합니다. 대신 새 앱은 앱 이름(패키지)이 달라서 **윈레이터(또는 그 포크)가 깔려
있어도 함께 설치됩니다.**

옮기는 순서:

1. 지금 쓰는 앱(0.1.12)에서 **세이브 → 올리기**로 세이브를 Steam 클라우드에 올립니다.
   불안하면 **저장공간으로 복사**도 한 번 눌러 `DD1/saves`에 사본을 남겨 두세요
2. 0.1.13 APK를 설치합니다. 기존 앱은 그대로 남아 있고, 아이콘이 하나 더 생깁니다
3. 새 앱에서 Steam에 로그인하고 게임을 받습니다. 저장소 권한을 물으면 허용하세요.
   게임은 `내장 저장공간/DD1/game`에 받아집니다(약 3.7 GB)
4. 새 앱에서 **세이브 → 가져오기**로 세이브를 받습니다
5. 창작마당 모드는 새 앱의 모드 관리자에서 다시 받습니다. `DD1/mods`에 직접 넣어 두었던
   모드는 `DD1/game/mods`로 옮기세요
6. 새 앱에서 게임과 세이브가 잘 되는 것을 확인한 뒤, 예전 앱을 지웁니다. 두 앱의
   이름이 같으니 앱 정보에서 버전이 0.1.12인 쪽을 지우세요

이번에 게임이 앱 밖(`DD1/game`)에 설치되기 때문에, 앞으로는 앱을 지웠다 다시 깔아도
게임을 다시 받지 않습니다.

### 게임이 내부 저장공간에 설치됩니다

**새로 설치하면 게임이 앱 안이 아니라 `내부 저장공간/DD1/game`에 받아집니다.** 모드
중에는 게임 파일을 직접 고치거나 DLL을 넣어야 하는 것이 많은데, 지금까지 게임은 앱
안에 있어서 파일 관리자로 닿을 수 없었습니다.

```
내부 저장공간/DD1/game
```

- PC에서 하던 것처럼 아무 파일 관리자로 열고, 넣고, 고칠 수 있습니다
- 처음 받을 때 저장소 권한을 묻습니다. 거부하면 지금처럼 앱 안에 받습니다
- 앱을 지워도 게임이 남습니다. 다시 설치하고 권한을 주면 있는 게임을 그대로 쓰고
  다시 받지 않습니다
- 설정 → 게임 파일에서 앱 안과 내부 저장공간 사이로 옮길 수 있습니다. 약 4 GB를
  복사하므로 그만큼 여유 공간이 잠시 필요하고, 도중에 취소하면 원래 자리의 게임은 그대로
  남습니다. 게임이 앱 안에 있을 때 홈 화면의 게임 파일 열기를 눌러도 옮길지 묻습니다
- 세이브는 게임과 함께 옮겨지지 않고 앱 안의 와인 프리픽스에 있습니다
- 받는 동안 게임 그림이 갤러리에 뜨지 않도록 숨겨 둡니다
- 내부 저장공간은 앱 안보다 읽기가 느립니다. 갤럭시 S22에서 플레이를 누르고 타이틀
  화면까지 앱 안은 약 27초, 내부 저장공간은 약 40초였습니다. 로딩이 신경 쓰이면 설정 →
  게임 파일에서 앱 안으로 옮길 수 있습니다

### 모드는 `DD1/game/mods`에 바로 넣습니다

**게임이 내부 저장공간에 있으면 `DD1/game/mods`가 곧 모드 폴더입니다.** 넣으면 바로
적용되고, `DD1/mods`에서 복사해 오는 단계가 없어졌습니다. ZIP 가져오기도 이 폴더에
바로 풉니다. 모드 관리자의 '폴더 열기'를 누르면 파일 관리자에서 이 폴더가 열립니다.

- 게임이 앱 안에 있으면 지금처럼 `DD1/mods`에 넣은 모드를 복사해 옵니다
- 모드 폴더를 직접 다른 곳으로 바꿔 둔 경우에도 지금처럼 그 폴더를 복사해 옵니다

### 게임 폴더를 런처에서 열 수 있습니다

**홈 화면에 게임 파일 열기와 게임 파일 검사 및 복구가 생겼습니다.**

- **게임 파일 열기**는 게임이 내부 저장공간에 있으면 휴대폰의 파일 관리자(삼성은
  내 파일)에서 게임 폴더를 엽니다
- 게임이 앱 안에 있으면 내부 저장공간으로 옮길지, 아니면 런타임의 윈도우 파일
  관리자로 열지 고를 수 있습니다. 윈도우 파일 관리자에서는 게임이 `G:`, 휴대폰의
  Download 폴더가 `D:`입니다. 넣은 DLL 때문에 게임이 켜지지 않을 때 그 파일을 빼는
  용도입니다
- **게임 파일 검사 및 복구**는 설치된 파일을 Steam 원본과 비교해서 달라진 부분만 다시
  받습니다. 덮어쓴 `Darkest.exe` 같은 것을 되돌릴 때 재설치가 필요 없습니다. 직접 넣은
  DLL처럼 Steam에 없는 파일은 지우지 않으니, 그런 파일은 게임 파일 열기에서 빼세요
- 휴대폰을 가로로 들면 버튼이 화면 밖으로 밀려나던 홈 화면을 스크롤할 수 있게 했습니다

### 다운로드가 끊겨도 처음부터 다시 받지 않습니다

**받던 다운로드가 멈추면 받은 부분을 남겨 두고 이어서 받습니다.** 지금까지는 Steam
서버가 3분 동안 응답하지 않으면 다운로드를 멈췄고, 다시 누르면 받은 것을 전부 지우고
처음부터 받았습니다. 연결이 느리거나 불안하면 데이터만 쓰고 진행률은 늘 제자리였던
이유입니다.

- 멈추면 잠시 뒤 다른 서버로 자동으로 다시 시도합니다. 최대 6번입니다
- 이어 받기 전에 이미 받은 파일을 조각 단위로 Steam의 체크섬과 대조합니다. 반쯤 쓰다
  만 파일이나 내용이 비어 있는 파일은 그 부분만 다시 받습니다
- 동시에 받는 연결 수를 2개에서 4개로 늘렸습니다

### 던전 이동 버튼

**오른쪽 여백에 ◀ ▶ 버튼이 생겼습니다.** 누르고 있는 동안 파티가 그 방향으로
걷습니다(A/D 키). 끌어서 이동하면 프레임이 떨어지던 문제를 피할 수 있습니다.

### 게임을 켤 때 로딩 화면

**플레이를 누르면 게임이 첫 화면을 그릴 때까지 로딩 화면이 나옵니다.** 지금까지는
"Starting up..." 창이 1~2초 뜬 뒤, 게임이 그려질 때까지 20초 넘게 버튼만 떠 있는 검은
화면이었습니다. 이제는 지금 런타임을 시작하는 중인지 게임을 불러오는 중인지 보여 주고,
게임이 그려지기 시작하면 사라집니다.

### APK가 작아졌습니다

**APK가 168 MB에서 113 MB로 줄었습니다.** Darkest Dungeon은 OpenGL 게임이라
Direct3D 변환기(DXVK 등)와 윈도우 구성 요소(Direct3D, XAudio, DirectSound 등)를 쓰지
않습니다. 게임 설정이 이것들을 끄도록 바꾸고 APK에서 뺐습니다.

- 첫 실행 때 이것들을 와인 프리픽스에 풀던 작업(약 40 MB)이 없어졌습니다
- 예전 버전에서 만들어진 게임 설정도 런처를 켤 때 자동으로 정리됩니다
- 게임이 켜지는 시간은 그대로입니다. 시간 대부분이 게임이 자기 파일을 읽는 데 쓰입니다

### 큰 모드

**모드 크기 제한 512 MB를 없앴습니다.** 400 MB짜리 통합팩 ZIP은 풀면 512 MB를 넘어서
들어오지 않았습니다. 이제는 휴대폰에 남은 공간만큼 들어오고, 공간이 모자라면 그렇게
알려 줍니다.

### 게임을 다시 받아도 모드가 남습니다

**게임을 재설치하거나 업데이트해도 설치된 모드를 지우지 않습니다.** 모드는 게임 폴더
안에 있어서 게임 폴더를 새로 바꿀 때 같이 사라졌고, 그래서 창작마당 모드를 전부 처음부터
다시 받았습니다.

### 모드 관리자와 설정 화면을 다시 정리했습니다

- **모드 관리자**: 위쪽 메뉴를 한 줄로 줄여서 가로 화면에 모드가 더 많이 보입니다.
  카드는 그림 옆에 글이 오는 모양으로 바뀌었고, 열 수는 화면 폭에 맞춰 정해집니다.
  내 모드 목록은 켜고 끄는 스위치와 상태 표시(최신, 업데이트 있음, 꺼짐 등)로 바뀌었고,
  구독 해제와 삭제는 ⋮ 메뉴 안으로 들어갔습니다. 화면 회전 버튼은 없앴습니다. 처음
  들어갈 때 목록을 불러오는 동안 빈 화면 대신 로딩 표시가 돕니다
- **설정**: 화면 · 그래픽 · 성능 · 게임 파일 · 일반 탭으로 나눴습니다. 그래픽 탭 맨 위에
  감지된 GPU와 지금 쓰는 드라이버가 나옵니다. 버그를 알려 주실 때 이 줄을 같이 보내
  주세요. 게임 위치는 지금 위치와 옮기기 버튼으로 바뀌었습니다
- 다른 다운로드나 창작마당 동기화 중에 다운로드·복구·DLC 받기를 누르면 아무 반응이
  없던 것을, 끝난 뒤에 다시 누르라고 알려 주도록 했습니다
- 확인 창 제목이 흰 바탕에 흰 글씨로 안 보이던 것과, 복구가 끝난 뒤에도 취소 버튼이
  남아 있던 것을 고쳤습니다

## 0.1.12

### 세이브가 앱 밖에도 남습니다

**앱을 지워도 세이브가 살아남는 사본이 생겼습니다.** 지금까지 세이브는 전부 앱 안에
있어서 파일 매니저로 닿을 수 없었고, 앱을 지우면 같이 사라졌습니다.

- 런처가 열릴 때와 게임을 마치고 돌아올 때, 세이브가 바뀌었으면 자동으로 한 벌을
  복사합니다. 최신 3벌만 남습니다

```
내부 저장공간/DD1/saves/auto
```

- 세이브 화면의 **저장공간으로 복사** 버튼은 지금 세이브 전체를 `DD1/saves/<시각>`에
  남깁니다. 이쪽은 자동으로 지워지지 않습니다 — 직접 지우기 전까지 남는 보관용입니다
- 파일 이름과 폴더 구조를 바꾸지 않고 그대로 복사합니다. 되돌릴 일이 생기면 게임을 끈
  상태에서 해당 파일을 원래 자리에 도로 복사하면 됩니다
- 저장공간 권한이 필요합니다. 모드 폴더를 쓰면서 이미 허용했다면 그대로 동작하고,
  아니면 버튼을 처음 누를 때 묻습니다. 허용 전에는 자동 복사도 조용히 기다립니다

### 만료된 로그인이 에러만 반복하게 될 문제

**Steam이 저장된 로그인을 거절하면 이제 로그인 화면으로 돌아갑니다.** 저장된 세션은
몇 달이 지나면 Steam이 더 받아 주지 않는데, 지금까지는 거절된 세션을 지우지 않아서
그때가 오면 매번 같은 에러만 보여 주고 빠져나갈 길이 없었습니다. 미리 고쳐 둡니다.
일시적인 연결 문제는 예전처럼 에러를 보여 주고 같은 세션으로 다시 시도합니다.

## 0.1.11

### 모드를 폴더에 넣어서 관리합니다

**모드 폴더가 생겼습니다.** 컴퓨터에서 하듯 폴더에 모드를 넣고 빼면 됩니다.

```
내부 저장공간/DD1/mods
```

- 모드 매니저를 열 때와 **새로고침**을 누를 때 이 폴더를 읽습니다. 생긴 것은 들여오고,
  없어진 것은 목록에서도 지웁니다
- 압축을 푼 폴더도, ZIP 파일 그대로도 받습니다. `project.xml`이 있는지로 판단합니다
- **ZIP 가져오기**는 이제 이 폴더에 압축을 풀고 나서 읽어들입니다. 그래서 ZIP으로 넣은
  모드도 폴더에서 빼면 사라집니다. 모드가 어디에 있는지가 한 곳입니다
- 목록에서 모드를 삭제하면 폴더의 원본까지 지웁니다. 그러지 않으면 다음에 화면을 열 때
  다시 들어옵니다
- 폴더 경로는 **변경**으로 바꿀 수 있습니다. 바꾸면 지금 폴더가 설치한 로컬 모드는
  제거되고 새 폴더를 읽습니다. 창작마당 모드는 어느 경우에도 영향받지 않습니다
- 설치된 목록이 **로컬 모드**와 **스팀 창작마당**으로 나뉩니다

이 화면을 처음 열 때 저장공간 권한을 한 번 묻습니다. 폴더를 읽는 데만 씁니다.

### ZIP으로 넣은 모드가 아무 일도 일어나지 않은 채 사라지던 문제

**창작마당을 거치지 않은 모드를 ZIP으로 넣을 수 있게 됐습니다.** 지금까지는 파일을 고르고
돌아와도 모드가 들어오지 않았고, 왜 안 됐는지도 말해 주지 않았습니다. 세 가지가 겹쳐
있었습니다.

- 파일 선택기가 화면을 가져가는 동안 런처는 설치 서비스와의 연결을 놓습니다. 돌아와서
  다시 연결하는 일은 파일을 받는 쪽보다 늦게 끝나므로, 고른 파일은 대개 아무에게도
  전달되지 않고 버려졌습니다. 이제는 연결이 돌아올 때까지 들고 있습니다
- 설치된 목록은 디스크에 있는 것인데, 스팀 응답을 기다리는 동안과 실패했을 때 그 목록이
  비워졌습니다. 로그인하지 않았거나 연결이 없으면 ZIP으로 넣은 모드는 스팀과 아무 상관이
  없는데도 목록에서 함께 사라졌고, 화면을 열 때마다 새로 고치므로 넣은 직후에만 보였습니다.
  이제 목록은 남고 메시지만 바뀝니다
- 파일 선택기가 ZIP만 고를 수 있도록 걸어 둔 조건이, 파일이 기기에 어떻게 들어왔는지에
  따라 그 ZIP을 회색으로 만들었습니다. 이제 종류를 가리지 않고, 안에 `project.xml`이
  있는지로 판단합니다

**게임 중에 Winlator 메뉴가 열리지 않게 바뀌었습니다.** 컨트롤러로 플레이하던 분이 알려주신
문제인데, 원인은 이랬습니다. Y는 게임에 배정된 버튼이 아니라서 안드로이드가 이를 뒤로가기로
바꾸고, 런타임은 뒤로가기에 왼쪽 메뉴를 여는 것으로 답하며, 그 메뉴의 첫 항목이 하필
`Keyboard`입니다. 그래서 두 번 누르면 키보드가 게임 위에 올라왔습니다.

- 이제 그 메뉴는 기본으로 열리지 않습니다. 뒤로가기도, 컨트롤러 버튼도, 네 손가락 탭도
  아무 일도 하지 않습니다
- 런타임 자체의 키보드나 작업 관리자, 종료가 필요하면 **설정 → Winlator 메뉴**에서 켜십시오
- 컨트롤러 입력 자체는 아무것도 가져가지 않습니다. 버튼은 예전처럼 게임으로 갑니다

### 키보드를 내린 뒤 버튼이 제자리로 돌아오지 않던 문제

키보드를 한 번 올리고 내리면 ABC·ESC·SHIFT+CTRL 버튼이 화면 중간에, 좌우로도 화면 끝에
붙은 채 남아 있었습니다. 버튼을 놓는 코드가 키보드가 떠 있을 때 예약된 값으로 자리를
정하는 경우가 있어서, 키보드가 사라진 뒤에 그 값이 도착하면 그대로 굳었습니다. 이제는
자리를 정할 때마다 지금 상태를 다시 읽습니다.

### 설치가 "앱이 설치되지 않았습니다"로 실패하는 경우

**기기에 Winlator가 이미 깔려 있으면 설치되지 않습니다.** 포크(Winlator Cmod 등)도
같습니다. 이 런처는 Winlator 런타임 위에서 돌고 패키지 이름을 그것과 공유하기 때문에,
안드로이드가 서명이 다른 같은 이름의 앱으로 보고 이유를 말하지 않은 채 거부합니다. 기존
Winlator를 지우고 설치하십시오. 한 기기에 둘을 함께 둘 수는 없습니다.

많이 불편했습니다. 이제 **태블릿은 가로를 유지하고 게임 화면을 키보드 위로 줄입니다.**

지금까지는 새 릴리즈가 나와도 알 방법이 없었고, 자기가 몇 버전을 쓰고 있는지도 런처 어디에도
안 나왔습니다. 이제 앱을 켤 때 한 번 확인해서, 더 새 버전이 있으면 알려주고 릴리즈 페이지를
열어 줍니다.

- **오늘 하루 보지 않기**를 누르면 그날은 다시 뜨지 않습니다. 날짜 기준이 이 기기의 시간대라
  하루가 끝나면 다시 알려줍니다
- 설치는 지금처럼 받은 APK를 위에 덮어 설치하시면 됩니다. **게임과 세이브, 모드는 그대로
  남습니다**
- 확인할 때 나가는 것은 아무것도 없습니다. 계정도, 기기 정보도 보내지 않고 공개된 릴리즈
  번호만 받아 옵니다

그 대가는 감당할 수 있습니다.

## 0.1.7

### 게임을 받는 동안 앱이 죽던 문제

**0.1.5에서 고친 것과 같은 오류인데, 다른 자리에서 났습니다.** 0.1.5는 이전에 죽으면서
남긴 프로필을 시작할 때 정리합니다. 이번 것은 프로필이 **지금 만들어지고 있는 동안**
읽혀서 났습니다.

프로필은 디렉터리를 만들고, 런타임 이미지를 그 안에 풀고, **마지막에** 설정 파일을 씁니다.
그 사이에는 설정이 없는 디렉터리입니다. 그런데 다운로드가 진행되면 런처가 초당 여러 번
화면을 새로 그리고, 그때마다 프로필을 읽습니다. 첫 실행에서 게임을 받으면 그 읽기가 그
빈틈에 떨어질 때까지 계속 시도되는 셈이라 사실상 반드시 걸렸습니다 — 그래서 "게임 받기만
하면" 죽었습니다.

이제 프로필을 읽지 못하는 순간은 "아직 프로필이 없다"로 답하고 넘어갑니다. 잠시 뒤 만들기가
끝나면 정상적으로 읽힙니다. 앱이 죽을 이유가 없어졌습니다.

**이 증상을 겪으셨다면** 앱을 지우지 마십시오. 이 버전을 위에 설치하면 됩니다. 앱 정보에서
캐시나 저장공간을 지워도 잠시 넘어가기는 하지만, 그건 만들기가 끝날 시간을 벌어준 것일 뿐
원인이 사라진 것은 아닙니다.

## 0.1.6

모드 관리자가 불안정했던 것들입니다.

### 다운로드 중에 다른 모드를 구독할 수 없던 문제

**구독을 눌러도 아무 일도 일어나지 않았습니다.** 런처가 "모드 동기화 중"과 "게임 다운로드
중"을 같은 값 하나로 판단하고 있었고, 구독이 그걸 보고 조용히 그만뒀습니다. 구독은
Steam에 요청을 보낼 뿐 파일을 건드리지 않으니 이제 언제든 됩니다.

파일을 만지는 것들(구독 해제, 활성/비활성, 삭제, ZIP 가져오기)은 여전히 다운로드 중에는
막힙니다 — 모드가 게임 폴더 안에 살고 게임 설치가 그 폴더를 통째로 바꾸기 때문입니다.
다만 이제는 조용히 무시하지 않고 **"다운로드가 끝난 뒤에 할 수 있습니다"라고 말합니다.**

### 구독 표시가 되돌아가던 문제

구독을 눌러 "구독 해제"로 바뀌었는데, 탭을 다녀오면 다시 "구독"이 되어 있었습니다.
카드의 구독 여부를 Steam이 준 목록에서 다시 계산하는데, 요청을 보내기 전에 이미 출발한
조회는 **구독 이전 목록**을 들고 돌아옵니다. 그 낡은 답이 화면을 덮었습니다.

이제 런처가 방금 요청한 구독을 Steam의 목록에서 실제로 확인될 때까지 따로 기억하고,
화면에 내보내는 모든 상태에 그것을 얹습니다. 버튼은 요청을 보내기 전에 즉시 바뀝니다 —
Steam은 한 번에 한 가지만 답하고 구독 목록 조회는 몇 초가 걸리므로, 그 왕복을 기다릴
이유가 없습니다.

### 두 개를 구독해도 대기열이 1개로만 보이던 문제

두 개를 연달아 구독하면 `1/2`처럼 보여야 하는데 계속 `1/1`이었습니다. 구독 완료 처리를
**동기화를 돌리고 있는 그 스레드에 맡겨두어서**, 그 처리가 다운로드가 끝난 뒤에야 실행됐고
두 번째 모드는 늘 별도의 1개짜리 동기화가 됐습니다. 그래서 "둘 중 첫 번째"라는 상황이
아예 만들어지지 않았습니다.

이제 대기열이 **받는 중에도 자랍니다.** 다운로드 도중에 확인된 구독은 돌고 있는 그 작업에
합류하고, 화면과 알림이 `1/2 · 모드 이름`으로 위치를 알려줍니다.

### Workshop 그림이 깜빡이고 목록이 위로 튀던 문제

동기화 중에는 스토어 목록이 **조각마다** 처음부터 다시 그려졌고, 그때마다 그림을 디스크에서
다시 읽었습니다. 그래서 그림이 깜빡이고, 스크롤이 위로 튀고, 구독을 누르려던 손가락 아래에서
카드가 바뀌었습니다.

진행 상황은 스토어에 있을 이유가 없습니다. **스토어 카드는 구독/구독 해제 토글만 남고
진행률 바를 없앴습니다.** 다운로드 현황은 내 모드 탭에서 봅니다. 목록은 목록 자체가
바뀌었을 때만 다시 그리고, 한 번 읽은 그림은 기억해 둡니다.

### 내 모드에서 상세 보기

설치된 모드의 행을 누르면 스토어와 같은 상세 창이 열립니다. 설명과 스크린샷도 같은
경로로 채워집니다. ZIP으로 가져온 모드는 Workshop 페이지가 없으니 열리지 않습니다.

## 0.1.5

### 다운로드 중에 앱이 죽은 뒤 아예 켜지지 않던 문제

**앱이 실행 즉시 닫히면 이 버전으로 올리십시오.** 게임 파일과 세이브는 그대로 있고,
덮어쓰기 설치만 하면 복구됩니다.

첫 실행에서 런처는 게임을 돌릴 프로필을 만듭니다. 그 과정은 디렉터리를 만들고, 압축된
런타임 이미지를 그 안에 풀고, **마지막에** 설정 파일을 씁니다. 4GB 다운로드가 기기를
물고 있는 동안 안드로이드가 앱을 정리하거나 사용자가 앱을 밀어 닫으면, 설정 파일이 없는
프로필 디렉터리가 남습니다.

그 뒤로는 실행할 때마다 죽습니다. 런처가 프로필을 읽으려 하면 없는 파일에서 빈 값이
돌아오고, 그것을 문자열로 만들다 그 자리에서 터집니다. 화면이 뜨기 직전이라 사용자에게는
"켜지지 않는다"로만 보이고, 다시 시도해도 같은 상태를 다시 읽으니 영구적입니다.

이제 앱이 시작할 때 프로필을 먼저 점검합니다. 설정을 읽을 수 없는 프로필이 있으면 그 안에
무엇이 있는지 보고 판단합니다.

- **세이브가 들어 있으면** 설정만 다시 써 넣습니다. 세이브와 Wine 프리픽스는 손대지
  않습니다
- **비어 있으면** 만들다 만 프로필이므로 지우고, 런처가 새로 만듭니다

실제로 이 증상이 난 태블릿(Galaxy Tab S8, Android 16)에서 확인했습니다: 고치기 전에는
같은 오류로 재현되고, 이 빌드를 덮어쓰니 정상 실행됐습니다.

이 구멍은 런처가 프로필을 갖게 된 날부터 있었습니다. 밟으려면 프로필을 만드는 그 몇 초
사이에 앱이 죽어야 해서 여태 드러나지 않았을 뿐입니다.

## 0.1.4

### 모바일 인증기가 없는 계정이 로그인하지 못하던 문제

Steam 가드는 두 길 중 하나로 확인합니다 — 모바일 앱에 승인을 요청하거나, 코드를
요구하거나. 런처는 앞의 것만 답하고 뒤의 것에는 그 자리에서 예외를 던졌습니다. 그리고
QR 로그인도 같은 모바일 앱으로 찍는 방식입니다. 그래서 **인증기를 쓰지 않고 이메일 코드로
확인하는 계정은 들어올 문이 아예 없었습니다.**

이제 Steam이 코드를 요구하면 로그인 화면 오른쪽에 입력칸이 나타납니다. 이메일로 온 코드든
인증기 앱의 여섯 자리든 같은 칸을 씁니다. 코드가 맞지 않으면 빈 칸을 다시 그리는 대신
맞지 않는다고 알려 주고, 취소하면 기다림이 즉시 풀립니다.

인증기로 승인하는 계정은 예전과 똑같습니다 — 승인 경로가 우선이라 입력칸은 나타나지
않습니다. 그것이 정상입니다.

실제 계정으로 확인했습니다: 인증기를 해제한 계정에서 이메일 코드를 받아 입력해 로그인까지
통과했습니다.

## 0.1.3

세 가지 버그를 고쳤습니다. 세 개가 같은 모양이었습니다 — 런처가 Steam이나 기기에게
물어보면 되는 것을 코드에 적어둔 목록으로 대신하고 있었고, 그 목록에 없는 것은 존재하지
않는 셈이 되었습니다.

### 세이브가 Steam 클라우드로 올라가지 않던 문제

**한 번도 성공한 적이 없었습니다.** Steam은 이미 같은 내용으로 갖고 있는 파일에 대해
"중복 요청"이라고 답합니다. 보낼 것이 없다는 뜻이고, 이미 보낸 것과 같은 상태입니다.
런처는 그것을 실패로 읽고 그 자리에서 슬롯 전체를 포기했습니다. 그리고 슬롯에서 가장
먼저 처리되는 파일이 거의 변하지 않는 파일이라, 첫 파일이 항상 중복이었습니다.

이제 변하지 않은 파일은 넘어가고 변한 것만 올립니다. 바뀐 것이 없는 슬롯을 다시
동기화하면 아무것도 보내지 않고 성공으로 끝납니다.

같이 고친 것: Steam이 거부한 이유가 로그에 남습니다. 예전에는 "커밋되지 않음"이라는
말만 있어서 무엇이 잘못됐는지 알 방법이 없었고, 그것이 이 버그가 오래 남아 있던 이유
입니다.

### 총사(The Musketeer) DLC가 설치되지 않던 문제

무료 DLC라 모든 구매자가 보유하고 있고, 모든 구매자가 받지 못하고 있었습니다. 런처가
DLC 목록을 코드에 적어둔 다섯 개짜리 표에서 읽고 있었고 총사는 그 표에 없었습니다.
목록에 없으니 화면에도 뜨지 않고, 선택되지도 않고, 다운로드되지도 않아서, 게임이
DLC가 없다고 말했습니다.

이제 목록을 Steam이 게임 정보로 내려주는 DLC 표에서 읽습니다. 앞으로 Red Hook이 DLC를
추가하면 런처를 고치지 않아도 그날부터 목록에 나타납니다.

덤으로, 여태 조용히 지나갔던 업데이트도 드러납니다 — 콘텐츠 화면에서 The Color of
Madness와 The Fire's Edge가 최신이 아니라고 알려 줍니다.

### 게임 화면이 검게 나오던 문제

**이런 현상이 있는 경우입니다.**

<p align="center">
  <img src="screenshots/09-black-picture.png" width="70%" alt="인터페이스와 대사는 나오지만 던전이 그려지지 않는 상태">
</p>

퀘스트 이름, 횃불, 영웅 창, 가방, 대사까지 다 나오는데 던전이나 마을만 검게 남습니다.
(증상을 그린 그림이며 게임 화면 캡처가 아닙니다.)

런처는 GPU 이름에서 모델 번호를 읽어 그래픽 드라이버를 고르는데, 여섯백·칠백·팔백번대
세 자리만 인식했습니다. 그 밖의 이름을 가진 Adreno는 "Adreno가 아닌 것"으로 처리되어
다른 드라이버를 받았고, 프로필의 나머지 설정은 Adreno 기준으로 맞춰져 있었습니다.
최신 기기에서 이 구멍에 빠집니다.

DD1은 게임 화면을 프레임버퍼에 그린 뒤 셰이더로 조명을 씌우고, 인터페이스는 그 경로를
타지 않습니다. 그래서 한쪽만 보입니다.

이제 번호가 아니라 이름으로 판단합니다. 이미 만들어진 프로필도 기기에 맞게 교정되므로,
업데이트만 하면 됩니다.

**다만 이것이 원인이라고 확정하지는 못했습니다.** 증상과 코드의 결함이 맞아떨어진다는
것까지가 지금 말할 수 있는 전부입니다. 그래서 아래를 같이 넣었습니다.

### 설정 화면에 그래픽 정보 추가

**위와 같은 현상이 있으면 서랍 → 설정 → 맨 아래 `그래픽 드라이버`를 봐 주십시오.**
GPU 이름과 지금 쓰는 드라이버가 적혀 있습니다.

<p align="center">
  <img src="screenshots/08-graphics.png" width="70%" alt="설정의 그래픽 드라이버 항목">
</p>

**이슈를 올릴 때 첨부해 주실 것:**

1. 위 두 줄 (그대로 적어 주시면 됩니다)
2. 기기 모델명과 안드로이드 버전 — 설정 → 휴대전화 정보 → 소프트웨어 정보
3. 검은 화면 스크린샷 — 인터페이스만 보이는 것과 전부 검은 것은 원인이 다릅니다
4. 어디서 그렇게 되는지 — 처음부터인지, 마을은 정상인데 던전만인지

로그까지 있으면 가장 좋습니다. USB로 연결한 PC에서 `adb logcat -d > dd1.log`.

세이브나 DLC 쪽 문제도 무엇을 보면 되는지 함께 정리해 두었습니다 —
README의 [문제가 생기면](../README.ko.md#문제가-생기면).

### 업데이트하는 방법을 README에 정리

이번에 The Fire's Edge가 실제로 업데이트됐는데, 그런 걸 어디서 보고 어떻게 받는지가
문서에 없었습니다. [업데이트](../README.ko.md#8-업데이트) 절을 새로 넣었습니다 — 런처
자체, DLC, 창작마당 모드 세 가지를 각각, 그리고 창작마당 동기화가 어디까지 왔는지 보는
곳 세 군데(내 모드 탭의 업데이트 표시, 화면 아래 진행 막대, 알림의 큐 위치)를 적었습니다.

### 내부 정리

동작에 드러나는 변화는 없습니다. 런타임이 이미 제공하는 파일·스트림 유틸리티를 쓰도록
바꾸고, 도달할 수 없던 코드 두 덩이와 쓰이지 않던 의존성 하나를 지웠습니다 — 더한 줄보다
지운 줄이 500줄 많습니다. APK가 0.1.2보다 2.9MB 작아진 것이 그 결과입니다.

DLC 커버 그림은 모드 이미지 캐시를 쓰게 되어 크기 제한과 축소 처리가 함께 적용되고,
목록의 커버를 다시 동시에 내려받습니다. 16KB씩 잘라 읽으며 문자열로 바꾸던 코드도 함께
사라졌는데, 그건 멀티바이트 문자가 경계에 걸리면 깨지는 코드였습니다.
