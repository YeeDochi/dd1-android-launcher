# DD1 Mod Hub Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the Workshop log screen with a searchable, image-backed Steam Workshop storefront and an installed-mod manager.

**Architecture:** Keep `DD1InstallService` as the single Steam and filesystem owner. Extend its immutable Workshop snapshot with browse results, join those results to subscriptions and active/disabled directories by published-file ID, and render two native Android tabs. Fetch preview images through a small bounded cache using only the standard library.

**Tech Stack:** Java 11, Android views/XML, JavaSteam 1.8.0, DepotDownloader, JUnit 4, AndroidX instrumentation.

**Spec:** `docs/superpowers/specs/2026-08-21-dd1-mod-hub-design.md`

## Global Constraints

- Keep `applicationId` as `com.winlator` and `targetSdkVersion` as `28`.
- Do not modify upstream files outside `com.winlator.dd1`, `dd1_*.xml`, `AndroidManifest.xml`, and `app/build.gradle`.
- Do not bundle game files, Workshop images, or other Darkest Dungeon data.
- Do not add an image-loading dependency.
- Never overwrite an existing active or disabled mod directory.
- Never run `connectedAndroidTest` on the phone; Waydroid only.
- Preserve all unrelated dirty files already in the worktree.

- [ ] **Step 3: Implement immutable browse state and service actions**
